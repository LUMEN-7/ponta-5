# Ponta de Cinco

Conversão do HTML fornecido para React + Vite, com fontes locais e layout responsivo.

## Executar

Requer Node.js 20.19+ ou 22.12+.

```sh
npm install
npm run dev
```

Para produção: npm run build. Para conferir o build: npm run preview.

A seleção das peças, as possibilidades de encaixe e os cálculos de pontos preservam o comportamento do original. Os botões Jogar peça, Passar a vez, Regras e Sair da mesa eram apenas visuais no arquivo original; não há motor de partida ou backend conectado.
